# Community Code of Conduct

Blockwater is developed in public. Contributors and maintainers are expected to discuss technical work respectfully and to judge proposals by evidence and project requirements.

Harassment, personal attacks, discrimination, threats, publishing private information without permission and persistent disruptive behavior are not acceptable. Good-faith disagreement, specific code review and the rejection of unsubstantiated claims are welcome.

Maintainers may moderate discussions, remove abusive content, reject contributions or restrict participation when necessary to protect contributors and the project. Reports concerning conduct should be sent privately to the repository maintainer through an available private contact channel; avoid posting private information in public issues. Security vulnerabilities have a separate [reporting policy](SECURITY.md).

These expectations apply to Blockwater repositories, issues, pull requests and project-managed discussions.
