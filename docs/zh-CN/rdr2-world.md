# RDR2 世界数据采集

[English](../rdr2-world.md) · [原生宿主](rdr2-host.md)

## 发布内容

原生插件通过故事模式检查并确认客体心跳实际推进后，才发布 ABI v1 `HostFrame`。`NativeWorld` 读取最终渲染相机的位置、旋转顺序 2 的角度及接口报告的 FOV。宿主角度保持度数：yaw 对应旋转 Z，pitch 对应 X，roll 对应 Y。投影、FOV 含义和 Minecraft 角度转换仍需游戏内校准；本链路不混入 gameplay camera 的位置或角度。

玩家脚底参考点由模型局部 `(0, 0, bounds.min.z)` 转换到世界坐标取得。这是模型包围盒下沿，不是骨骼或动画测量。蹲伏、骑乘、替换玩家模型和斜坡接触需要游戏内对比，才能判断该参考点的接触精度。相机、FOV、模型边界或坐标缺失、非法时，整帧失效，不发布虚构的零坐标。

帧包含单调序号、采样时间、非零锚点、以初始脚底为宿主原点的转换关系、客体原点 `(0, 64, 0)` 和一米一格的比例。会话更新、非法观测恢复、单次位置变化超过 32 米、距原点超过 128 米或时钟不连续时，重新锚定并清除地形。锚点数值耗尽时使输出失效，不复用旧编号。客体须拒绝非法或过期帧，并在锚点变化后重建相关数据。

## 异步地形

`WorldStream` 按由近到远的方形环采集 9 × 9、间距两米的网格，最多发布 81 个有效观测，保留现有 ABI 的 96 个采样容量。玩家进入另一网格或参考高度变化超过两米时，网格失效。这是局部高度采样，不是墙壁、围栏、室内和多层楼面的完整碰撞网格。

低位射线从脚底参考高度上方两米向下探测至下方 80 米；确定未命中后，在后续轮次从上方 150 米探测至上方两米。形状测试选择静态世界几何，排除玩家，并使用碰撞选项 4；本批不表达动态实体。命中点须有限且位于请求的垂直线段内，法线须有限且长度合理。`TerrainSample.flags = 1` 表示实际命中；缺失、非法、过期和未完成观测直接省略，不填充假地面。原生实体数量在本批保持为零。

同时最多持有八个引擎探测句柄，每帧对每个已有句柄最多查询一次，最多启动八个新探测。采集用时达到 500 微秒后停止派发；该预算不能抢占单次 Native 调用，不代表实测游戏帧耗时保证。不使用同步昂贵射线、等待循环或逐帧堆内存分配。

超过 250 毫秒的结果被丢弃，但未完成句柄继续占用原槽位，直到引擎报告完成或失效后才释放；不会不断创建替代句柄。因此引擎停滞可能使地形采集停滞，但不会导致句柄数量无界增长。有效采样在 500 毫秒后过期。暂停、断连和多人模式拒绝均停止采集；只有恢复到允许的已连接会话后才回收残留探测，旧结果不能进入新网格。卸载时不在加载器锁下调用 Native；真实引擎对未完成探测的回收仍属于游戏内重载验收。

## Native 契约

名称、哈希和签名来自 [RDR3 Native DB](https://github.com/alloc8or/rdr3-nativedb-data/blob/master/natives.json)，核查版本为 blob `292f072816470c5dee885f4270861db38bffd406`。完整接口表见[英文契约](../rdr2-world.md#native-contract)，ScriptHook 参数与向量布局依据[原生宿主接口登记](../rdr2-host.md#native-interface-register)。源码核查不构成游戏版本兼容性验收。

整数和浮点位模式放入预先清零的 64 位参数槽低位；指针保留完整 x64 值。Native 向量占三个八字节槽，浮点分量分别位于偏移 0、8、16。输出缓冲以 NaN 初始化，未写入结果不能变成有效原点。`GET_MODEL_DIMENSIONS` 为 void 调用，以实际输出值判断成功，不以返回指针判断。探测状态 0 释放失效句柄，1 保留未完成句柄，2 处理完成结果；缺失或未知状态继续保留句柄，不将输出当成命中。

## 验证与待验收项

`blockwater_world_stream` 覆盖采集、非法值拒绝、采样过期、派发预算、启动失败、时钟回退、重新锚定、未完成探测数量上限、计数耗尽与 Native 参数编码。Windows 加载器新增八个实际 `.asi` 场景，分别覆盖非法相机、相机结果缺失、非法模型边界、传送、暂停、持续未完成地形、未命中与非法法线。测试运行库独立检查 Native 哈希、参数数量、标量位模式、输出向量布局、玩家排除和脚本协程归属，保留既有生命周期、请求拒绝和安装检查。

[CI 第 8 次运行](https://github.com/ranzevor/Blockwater/actions/runs/38656719116)验证源码 `8c4aaba9ce27d5121a4ffb5bfa24e09938d6325e`：Windows x64/MSVC 构建插件并通过 31 项 CTest，Ubuntu 构建和测试通过。Linux 中九组采集/参数用例另外通过 GCC、Clang 和 ASan/UBSan，GCC 套件连续重复 30 次通过。

游戏验收须记录实际 RDR2 和 ScriptHook 版本，对比最终相机/FOV及模型脚底参考点，测量查询和帧循环耗时，检查屋顶与流式加载边界的地形，以及卸载/重载中的未完成探测回收。真实碰撞对象、附近实体发布、Fabric 接入和 GPU 合成仍属后续工作。本批不构成可玩发行版，也不代表整个 B1 完成。
