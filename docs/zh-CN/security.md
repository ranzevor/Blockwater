# 安全问题报告

[English](../../SECURITY.md)

安全修复以当前 `main` 分支和明确标记仍维护的发行版本为范围。目前没有稳定版或可玩的实机发行版；当前实现包含共享内存 IPC 与宿主适配契约，游戏进程 Hook 和图形融合尚未完成。

不要在公开 Issue 中披露可执行的漏洞利用步骤或私人信息。若仓库已启用 GitHub 私有漏洞报告功能，请通过 **Security → Report a vulnerability** 报告；否则使用仓库维护者公开提供的私密联系方式。如果暂时找不到私密渠道，不要把漏洞细节发送到公开讨论。

报告应提供受影响版本／提交、影响范围、可复现步骤及不包含游戏专有资产或个人数据的最小示例。维护者将核对影响并通过正常审查流程协调修复。

Blockwater 仅支持 RDR2 故事模式；绕过反作弊、修改 Red Dead Online 或未经授权访问其他玩家系统，不属于本项目支持范围。被拒绝的多人模式不得回退进入具备改写游戏能力的状态。
